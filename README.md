## ⚡ Ключевые возможности

### 🛡️ 1. Zero Telemetry & Privacy Shield
* **Полная изоляция Chromium**: Отключены встроенные механизмы сбора метрик Google (`disable-metrics`, `disable-breakpad`, `disable-domain-reliability`, `disable-sync`).
* **Аппаратный блокировщик трекеров O(1)**: Мгновенно перехватывает и срезает запросы к Google Analytics, Yandex Metrika, счетчикам посещений и шпионским пикселям.
* **Автоочистка ссылок**: Срезает трекинговые UTM-хвосты (`utm_source`, `fbclid`, `gclid`, `yclid`) при навигации.
* **Do-Not-Track & Sec-GPC**: Принудительная отправка строгих заголовков приватности всем сайтам.
* **100% Локальные данные**: История, закладки, пароли и настройки хранятся только локально в зашифрованных файлах.

### 🧠 2. Tab Hibernation & RAM Optimizer
* **Интеллектуальная гибернация неактивных вкладок**: Фоновые вкладки, простаивающие более 5 минут, автоматически усыпляются — их тяжелые процессы выгружаются из RAM, освобождая до 150–250 МБ на вкладку.
* **Мгновенное пробуждение**: Восстановление вкладки в один клик без потери позиции скролла и данных формы.
* **Монитор сэкономленной памяти**: Верхний счетчик показывает освобожденную оперативную память в реальном времени.

### 🌐 3. Встроенный VPN с поддержкой HWID & Замер пинга
* **Полная поддержка современных протоколов**: `VLESS REALITY`, `VMess`, `Trojan`, `Shadowsocks`, `SOCKS5`, `HTTP`, форматы `sing-box JSON`, `Happ`, `INCY`, `v2ray`, `Clash`.
* **Поддержка привязки по HWID**: Браузер генерирует уникальный аппаратный идентификатор и корректно работает с панелями *Remnawave*, *Marzban* и подписками *Happ/INCY*, предотвращая ошибку «Приложение не поддерживается».
* **Замер пинга в реальном времени (⚡)**: Параллельный замер сетевой задержки до каждого сервера с цветовой индикацией (зеленый/желтый/красный).
* **Удобная карточка подписки**: Отображение остатка трафика, дней, кнопки обновления в 1 клик и копирования HWID.

### 🧅 4. Tor Onion Routing & Мосты (@GetBridgesBot)
* **Анонимная маршрутизация**: Доступ к сайтам зоны `.onion` и защита сетевого уровня.
* **Обход цензуры**: Встроенная поддержка мостов `obfs4` и `webtunnel` с возможностью быстрой вставки конфигураций от официального Telegram-бота `@GetBridgesBot`.
* **Настройка запуска**: Выбор режима при старте (всегда Tor / стандартный / запрос).

### 🌙 5. Нативный Dark Mode Engine
* Принудительный темный режим на уровне Chromium с передачей темных тем в поисковики (DuckDuckGo, Brave, Google, Yandex).
* **Zero White Flash**: Отсутствие белых вспышек при открытии и переключении вкладок.

### 🔑 6. Менеджер паролей (AES-256-GCM Vault)
* Надежное локальное шифрование логинов и паролей с автоматическим предложением сохранения и автозаполнением форм.

## ⌨️ Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl + T` | Открыть новую вкладку |
| `Ctrl + W` | Закрыть текущую вкладку |
| `Ctrl + L` | Фокус на адресную строку |
| `Ctrl + R` | Перезагрузить страницу |

| `Ctrl + D` | Добавить страницу в закладки |
| `Ctrl + F` | Поиск по странице |
| `Alt + ←` / `Alt + →` | Назад / Вперед |
| `Escape` | Закрыть модальное окно / поиск |

## 🛠️ Сборка из исходников

Для самостоятельной сборки приложения требуется [Node.js](https://nodejs.org/) (версии 18+):

```bash
# Клонирование репозитория
git clone https://github.com/eahider/aura-browser.git
cd aura-browser

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка готового установщика для Windows x64 (v1.0.0)
npm run dist
```

Также в корне проекта подготовлены автоматические скрипты:
* `run.bat` — быстрый запуск приложения.
* `build_desktop.bat` — полная компиляция и создание установщика в папку `dist/`.
